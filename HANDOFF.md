## Что представляет собой проект

Midnight Launcher 0.2.0 — десктопный Minecraft-лаунчер на React/TypeScript
и Tauri 2/Rust. Интерфейс на русском и английском.

- Библиотека сборок, поиск, фильтры Java/Horizon, отдельные настройки сборок.
- Vanilla, Fabric, современный Forge и NeoForge; установка Minecraft и Java.
- Локальные моды, каталоги Modrinth/CurseForge, модпаки Modrinth.
- Нативный Horizon 0.2.97 для Minecraft 26.3; ресурсы готовятся отдельно.
- Microsoft/Xbox/Minecraft-вход, проверка владения игрой, защищённое хранение
  сессий. Оффлайн-профиль требует ранее подтверждённого аккаунта.
- Темы, настройки внешнего вида/Java/лаунчера, адаптивная навигация.
- Фирменный Windows NSIS-установщик с RU/EN и нативной темой.

Основные файлы: `src/App.tsx`, `src/components/`, `src/api.ts`, `src/model.ts`,
`src/i18n.ts`, `src/theme.css`, `src/layout.css`; команды Tauri находятся в
`src-tauri/src/lib.rs`, авторизация в `src-tauri/src/auth/`, установка и запуск
игры в `src-tauri/src/minecraft/`. Правила изменений — в `AGENTS.md`.

## Проверки и ограничения, которые важно не потерять

`VERIFICATION.md` — журнал разных этапов, а не единый актуальный итог.
Поздние датированные записи могут отменять ранние. `README.md` и
`MICROSOFT_SETUP.md` также содержат исторические формулировки: при противоречии
сверять дату, конкретное наблюдение и код, не объявлять успех без проверки.

- 1 ноября проверены сборка Windows и изолированные установка, повторная
  установка, удаление, сохранение постороннего файла и SHA-256 установленного EXE.
  Первый запуск без WebView2 и подпись Windows-пакета отдельно не проверены.
- Свежие функции Windows не следует считать проверенными на macOS только
  потому, что более ранняя Apple Silicon сборка когда-то проходила.
- В записи от 31 октября о Horizon через кнопку Launch отмечены успешные
  восстановление аккаунта и проверка лицензии, подготовка ресурсов и запуск
  `horizon-client`. Проверку окон остановил пользователь. Это не подтверждает
  новый полный Device Code Flow, игру в мире или вход на online-mode сервер.
- Отдельно проверены подготовка Horizon и его нативное меню в изолированном
  режиме без аутентификации. Не смешивать эти два сценария.
- Владелец ранее сообщил об одобрении собственного Mojang AppID. Встроенный
  Client ID публичный, детали в `MICROSOFT_SETUP.md`. Чужие ID не использовать.
- Реальные авторизованные операции CurseForge требуют своего ключа и пока
  не подтверждены. Ключ хранится только в памяти Rust.
- Для одиночных модов актуальные лимиты: 512 МиБ на файл, 2 ГиБ на операцию,
  64 файла зависимостей. У модпаков свои ограничения — см. README и код.
- Horizon поддерживает Windows x64, Linux x64 и Apple Silicon. Установка
  Java-инстансов реализована для Windows x64 и Apple Silicon; Linux Java
  пока не поддерживается. Новую ОС пользователя нужно учитывать при восстановлении.
- Полные игровые проверки и совместимость произвольных сторонних модов не
  подтверждаются одним успешным скачиванием, сборкой или запуском меню.

## Как возобновить работу

1. Клонировать репозиторий и открыть папку как проект в Codex.
2. Прочитать `AGENTS.md`, эту памятку, `README.md`, свежие датированные разделы
   `VERIFICATION.md` и `MICROSOFT_SETUP.md`.
3. Установить Node.js 22 и Rust 1.99+, выполнить `npm ci`.
   Для Windows нужны MSVC x86/x64 Build Tools и Windows SDK; для macOS —
   соответствующие Apple Command Line Tools и target. Подробности в README.
4. Для проверки среды: `npm test`, `npm run build`. Browser preview через
   `npm run dev` не выполняет нативные команды. Для приложения — `npm run tauri -- dev`.
5. Нативные команды сборки: `npm run build:win -- --ci -- --locked` или
   `npm run build:mac`, в зависимости от ОС. Не скачивать гигабайты игровых
   ресурсов только ради восстановления контекста.
6. Продолжить с новой задачей пользователя; незавершённого изменения кода
   от этого чата нет. Общение вести на русском, объяснять результат кратко.

При прежней отправке GitHub-подключение приложения читало репозиторий, но
получало 403 на запись. Обычный Git заработал после входа владельца через
Git Credential Manager. На новой системе может потребоваться войти заново.
Секреты и сырую папку настроек Codex в публичный репозиторий не загружать.
