# Настройка Microsoft для Midnight Launcher

В сборку добавлен Client ID владельца Midnight: `6b0fede0-1318-4335-908d-a668b7599747`. Это публичный идентификатор, не секрет. Пустое поле из старых настроек автоматически заполняется им; свой ранее сохранённый ID сохраняется. 30 октября 2026 владелец сообщил об одобрении AppID Mojang и подтвердил, что заявка относится к этому ID. Успешное завершение всей цепочки входа реальным аккаунтом по-прежнему требует проверки.

В Midnight нет встроенного чужого Client ID. Чтобы войти, владелец проекта должен зарегистрировать собственное публичное приложение. Один зарегистрированный Client ID затем используется пользователями этой сборки — каждому игроку не нужно регистрировать отдельное приложение.

## Регистрация

1. Откройте [Microsoft Entra — App registrations](https://entra.microsoft.com/#view/Microsoft_AAD_RegisteredApps/ApplicationsListBlade) и войдите своим аккаунтом владельца проекта. Если нет доступа к каталогу, потребуется доступный вам Entra tenant с правом регистрации приложений. Регистрация приложения и владение Minecraft — разные вещи.
2. Выберите **New registration**, название **Midnight Launcher**.
3. Выберите поддержку **Personal Microsoft accounts** (или вариант с организационными и личными аккаунтами). Midnight обращается к authority `consumers`; рабочие/учебные аккаунты сами по себе не подходят для Minecraft Java.
4. Для используемого Device Code Flow callback/redirect URI не используется. Секрет приложения не создавайте: десктопный лаунчер является публичным клиентом.
5. В **Authentication → Advanced settings → Allow public client flows** включите **Yes** и сохраните. В обновлённом интерфейсе Microsoft названия разделов могут отличаться.
6. Скопируйте **Application (client) ID** со страницы Overview. Это публичный UUID, не пароль.
7. Встроенный Client ID настраивается разработчиком в `src/model.ts`; поле скрыто в пользовательском интерфейсе.
8. Откройте **Accounts → Sign in with Microsoft**. Лаунчер запрашивает настоящий одноразовый код. Нажмите **Open Microsoft**, введите код и завершите вход на официальном сайте Microsoft.
9. Разрешения flow: `XboxLive.signin offline_access`. Midnight не запрашивает пароль, Microsoft Graph, доступ к почте или файлам.

Не присылайте в чат пароль, refresh token, client secret или коды MFA. В процессе реального входа может появиться штатное окно доступа macOS к записи Midnight в Keychain.

## Доступ к Minecraft API

Регистрация Client ID не означает, что Minecraft Services примет приложение. Проверьте актуальный процесс **Java Edition Game Service API Review or Application Process** через [официальный раздел поддержки Java Edition](https://help.minecraft.net/hc/en-us/sections/44460521913485). Если для приложения требуется заявка/одобрение Mojang, его нужно пройти отдельно.

Общий HTTP 403 на Minecraft Services означает отказ запроса; сам по себе он не доказывает отсутствие одобрения приложения. Midnight показывает отдельное сообщение о регистрации только если сервер явно вернул `Invalid app registration`. При неопределённом 403 или недоступном `/launcher/login` (404/405) лаунчер один раз пробует стандартный `/authentication/login_with_xbox` с тем же XSTS-токеном. При явном отказе регистрации, 401, 429, сетевых/серверных ошибках и отмене запасной запрос не выполняется. Каждый успешный вариант затем проходит штатную проверку лицензии и профиля. Чужие Client ID не используются.

При отказе обмена токена в разделе «Аккаунты» появляется «Диагностика входа»: фактический публичный Client ID, фиксированные адреса Minecraft Services, HTTP-статусы и локальные коды ошибок. «Копировать сведения» копирует только эти поля. Пароли, device codes, токены и тела ответов туда не попадают. Диагностика хранится только в памяти до следующей попытки/выхода. Она учитывает и Client ID из сохранённой сессии, который может отличаться от встроенного значения.

После установки исправленной версии сначала можно нажать «Восстановить сохранённый вход». Если Microsoft-подтверждение уже прошло, refresh token мог сохраниться в системном хранилище даже при последующем отказе Minecraft. Если сохранённой сессии нет или она истекла, начните новый вход через Microsoft.

## Что проверяет лаунчер

Microsoft device code → Microsoft access token → Xbox user token → XSTS → Minecraft launcher token → `game_minecraft` entitlement → Minecraft profile. Успешным считается только завершение всей цепочки.

При истечении кода, отказе пользователя, ошибке настройки Client ID, отсутствии Xbox-профиля, семейных ограничениях или отсутствии лицензии вход завершается соответствующей ошибкой. Кнопка Cancel прекращает дальнейшие этапы; уже выполняющийся HTTP-запрос ограничен таймаутом. Подтверждённого успешного входа реальным аккаунтом у этой сборки пока нет, хотя Client ID владельца уже предоставлен.

Хранится один активный аккаунт. Для смены аккаунта выйдите из текущего, затем начните новый вход. Refresh token сохраняется в системном Keychain, обновляется при refresh и удаляется при Sign out. Access tokens обрабатываются только в Rust и передаются Microsoft/Xbox/Minecraft и запущенному игровому процессу.

В режиме Microsoft Horizon 0.2.97 принимает аккаунт через одноразовый `--session-file`: Midnight создаёт JSON с именем, UUID, Minecraft access token и XUID с правами только текущего пользователя (защищённый DACL Windows / 0600 Unix). Клиент читает и сразу удаляет файл; при ошибке или отмене запуска Midnight удаляет его сам, а просроченные файлы после аварии убираются при следующем запуске. Токен не включается в аргументы процесса, переменные окружения, IPC или диагностику. После длительной подготовки ресурсов сессия повторно проверяется на срок действия перед передачей. Вход в отдельный Horizon Launcher не требуется.

Оффлайн-профили Java и Horizon разблокируются только после успешного Microsoft-входа с проверкой лицензии Minecraft Java и игрового профиля. Сохранённый refresh token без подтверждённого профиля доступа не даёт. Подтверждение хранится в системном хранилище и сохраняется после перезапуска; выбор ника в localStorage его не заменяет. Rust проверяет доступ при выборе оффлайн-профиля, до установки и ещё раз перед запуском игры. Оффлайн-режим выбирается явно и не обновляет Microsoft-токены; серверы с online-mode для него недоступны. Первая установка требует интернета.

При открытии «Аккаунтов» читается только локально сохранённое подтверждение, без сетевого восстановления входа; автоматическая проверка при старте приложения системное хранилище по-прежнему не читает. «Выйти из аккаунта» удаляет подтверждение и сбрасывает выбранный оффлайн-ник. Выйти можно и из сохранённого аккаунта без повторного онлайн-входа. Restore размещена отдельной строкой под кнопкой Microsoft с отступом 12 px.
