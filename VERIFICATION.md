# Проверка Midnight Launcher 0.2.0

28 октября 2026, macOS arm64, Rust 1.99.1, Node.js 24.22.1.

## Подтверждено исполнением

- TypeScript и Vite production build успешны.
- Vitest: 9 тестов прошли — восстановление состояния, миграция настроек, валидация инстансов.
- Rust: 17 тестов прошли — разрешённые пути/хосты, SHA-1, порядок rules, features, выбор ARM64 natives из реального JSON 1.21.1, безопасные ссылки архива Java, целостность аргументов с пробелами, отсутствие токенов в ошибках, отменённый polling и запрет запуска без game_minecraft entitlement.
- Реальный установщик через `examples/prepare.rs` скачал Vanilla 1.21.1 в каталог данных Midnight: клиент, 55 библиотек, 3888 уникальных объектов ресурсов и конфигурацию логирования Mojang. Повторный прогон переиспользовал кэш после проверки хешей.
- Установлена локальная Temurin JRE 21.0.13+9 aarch64. Проверены SHA-256 архива, распаковка, версия и архитектура через настоящий процесс Java.
- Отдельный JVM probe загрузил главный класс Minecraft без его запуска, LWJGL и GLFW. Результат:

```text
Minecraft main class found; Java 21.0.13 aarch64; LWJGL 3.3.3+5; GLFW 3.4.0 Cocoa NSGL Null EGL OSMesa monotonic dynamic
```

`src-tauri/tests/RuntimeProbe.java` — исходник этой проверки. Он компилировался установленным JDK с `--release 21`, затем выполнялся установленной лаунчером Java 21 с classpath, выданным `examples/prepare.rs`. Проверка не использует аккаунт, не подставляет игровые токены и не запускает игровой профиль.

- Release `.app` и DMG созданы под aarch64-apple-darwin. Используется локальная ad-hoc подпись; целостность приложения проверена codesign, образа — hdiutil verify.
- В браузере проверены новая форма Accounts и честная ошибка desktop-only при попытке входа из превью: подставного кода или аккаунта не появляется.
- В окне About видна запрошенная пользователем фраза. Computed styles подтверждают `quote-shimmer` и градиент из токенов активной фиолетовой темы. Уменьшение движения отключает анимацию стилями, сохраняя градиент.
- Сохраняется адаптивная компоновка с постоянно видимой нижней навигацией; проверялись 1160×790, 760×650, 640×480 и 390×700.

## Не подтверждено

- Успешный Microsoft Device Code Flow реальным аккаунтом: Client ID владельца добавлен; настройки public client flows и вход ещё не проверены. Обработка протокола реализована и компилируется, но OAuth/Xbox/XSTS/Minecraft нельзя объявить end-to-end проверенными.
- Одобрение Client ID со стороны Minecraft API отсутствует/неизвестно. Регистрация и её допуск выполняются владельцем по MICROSOFT_SETUP.md.
- Keychain UX с настоящим refresh token, обновление реальной сессии, реальный выход и отказ реального пользователя в Microsoft.
- Появление игрового окна, загрузка мира, multiplayer, обработка всех реальных игровых аварий. Проверка Java/LWJGL не равна запуску Minecraft с лицензированным аккаунтом.
- Отображение нативного Tauri-окна в этой среде: Computer Use не имеет разрешений управления приложениями macOS. Браузерное превью не выдаётся за нативную UI-проверку.
- Другие версии Minecraft, ОС, Intel/Rosetta, модлоадеры, Game Pass lifecycle и все варианты семейных ограничений.
- CI, Developer ID и notarization Apple: не выполнялись/не настроены. Защиты macOS не отключались.

## Оффлайн-профили

Добавлены локальный выбор ника, миграция настроек и независимый путь запуска. Rust-тест проверяет Java-совместимый UUID для Notch и отклонение некорректных ников. Полный игровой запуск оффлайн-профилем не проверен.

## Окно логов

Добавлено чтение хвоста stdout/stderr по ID инстанса, без произвольного пути из интерфейса. Тест проверяет отсутствующий файл, отклонение выхода из каталога и ограничение чтения 256 КБ. Отображение настоящих игровых логов в нативном окне пока не проверено.

## Fabric

Выбор Vanilla/Fabric, закрепление версии, применение официального профиля и библиотек реализованы. Тестируется официальный JSON 1.21.1 + Fabric 0.16.14, пути Maven и отказ для неподдерживаемых загрузчиков. Игровое окно Fabric и совместимость произвольных модов не проверены. Лог JVM теперь записывается под ID инстанса, совпадающим с запросом окна логов.

Реальный `examples/fabric.rs` успешно получил версии Fabric для 1.21.1, скачал и проверил 8 библиотек Fabric 0.16.14. Entry point: `net.fabricmc.loader.impl.launch.knot.KnotClient`. Игровая JVM при этой проверке не запускалась.

## Оформление списков

Заменены native select и datalist на общий тематический combobox/listbox. В браузере проверено открытие списка инстансов и наличие его пунктов; форма создания показывает новые поля версий и загрузчика. Полная клавиатурная и визуальная проверка не завершена: соединение браузерного инструмента оборвалось.

## Редактор сборок и поведение окна

В браузере проверены отсутствие ручной установки и нижней строки главного экрана, новые настройки поведения, расположение логов, открытие редактора существующего инстанса и заполнение его данных. Тест модели проверяет сохранение индивидуальной памяти/Java/цвета и настроек окна, очистку некорректных необязательных полей без удаления инстанса. 9 frontend- и 17 Rust-тестов прошли. Системное сворачивание и возврат окна после реального игрового процесса не проверены.

## Анимации

В браузере computed styles подтвердили `menu-arrive` и `midnight-drift`. При включении Reduce motion оба становятся `none`, переход навигации — `0s`. Исходное значение пользовательской настройки восстановлено после проверки. 9 frontend-тестов прошли. Производительность нативного WebView отдельно не измерялась.

## Окно редактора

В браузере проверены открытие модального Customize instance, выбор Fabric и появление его полей. Позиция меню проверена по DOM: на 6 px ниже поля. Данные пользовательского инстанса в этой проверке не сохранялись.

## Новый выбор сборки

В браузере визуально проверена упрощённая главная страница и открытие диалога выбора. Нажатие текущей сборки закрывает диалог; существующие пользовательские сборки сохранены.

В браузере проверен новый полноширинный блок консоли, открытие меню инстансов внутри диалога и переключение на другой инстанс без изменения Launch-выбора. В браузерном превью показано честное сообщение об отсутствии нативного доступа к файлам.

## Дополнительные палитры

10 frontend-тестов прошли, включая восстановление всех девяти тем. В браузере проверены применение Nord (`--rose: #88c0d0`) и визуальное оформление Catppuccin Mocha. После проверки восстановлена исходная Graphite.

## Пользовательские палитры

East Bay, Coastal Blue и Charcoal & Ivory проверены в браузере: computed styles совпали с основными HEX из изображений. East Bay визуально проверена на главной. Исходная Graphite восстановлена после проверки. 10 тестов прошли, включая восстановление всех 12 ID тем.

## Keychain при старте

`get_account` возвращает только профиль активной сессии в памяти. Автоматическое чтение Keychain при запуске удалено; сохранённый вход восстанавливается явной командой `restore_account`. Регрессионный Rust-тест проверяет пустой профиль нового AuthManager без обращения к хранилищу. Реальный системный диалог после восстановления Microsoft-входа зависит от разрешений Keychain и подписи сборки.
